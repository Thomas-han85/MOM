# 폰과 컴퓨터 회의록 연동 — 준비

회의록 글자를 구글 드라이브의 **전용 폴더**에 올려 두 기기가 같은 내용을 본다.
드라이브 화면에는 보이지 않고 다른 앱도 볼 수 없다. 오디오는 올리지 않는다.

로그인은 **기기 흐름**을 쓴다. 앱이 짧은 코드를 보여 주면 아무 브라우저에서 그 코드를
넣어 승인하는 방식이다. 구글은 앱 안의 WebView 로 직접 로그인하는 것을 막아 두었는데,
이 방식은 그 제약을 피하면서 폰과 컴퓨터가 똑같은 코드 한 벌로 동작한다.
한 번 승인하면 계속 유지된다.

준비는 약 10분. 한 번만 하면 된다.

---

## 어느 구글 계정으로 할 것인가

두 가지가 따로다.

1. **회의록이 저장될 계정** — 승인할 때 고른다. 아무 계정이나 된다.
2. **아래 설정을 만들 계정** — 프로젝트 주인. 1번과 같아도 되고 달라도 된다.

헷갈리지 않으려면 둘을 같은 계정으로 두는 편이 낫다.

---

## 1. 프로젝트와 API

https://console.cloud.google.com 에 **설정을 만들 계정**으로 접속.

1. 처음이면 이용약관 동의 화면이 나온다. 읽고 동의한다.
2. 상단 프로젝트 선택 → **새 프로젝트** → 이름 `meetnote` → 만들기
3. 좌측 메뉴 **API 및 서비스 → 라이브러리** → "Google Drive API" 검색 → **사용 설정**

## 2. 동의 화면

**API 및 서비스 → OAuth 동의 화면**

1. User Type **외부(External)** → 만들기
2. 앱 이름 `trans-mom`, 지원 이메일과 개발자 이메일을 넣고 저장
3. 범위(Scope)와 테스트 사용자는 건너뛴다
4. **대시보드에서 "앱 게시(Publish app)" → 프로덕션으로 전환**

4번이 중요하다. 테스트 모드로 두면 로그인이 7일마다 풀린다.
우리가 쓰는 `drive.file` 는 비민감 범위라 심사 없이 게시된다.

## 3. 클라이언트 만들기

**API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**

- 애플리케이션 유형: **TV 및 제한된 입력 장치** ← 이것 하나만 만든다
- 이름: `meetnote-device`
- 만들기

나오는 **클라이언트 ID** 와 **클라이언트 보안 비밀(시크릿)** 을 복사해 둔다.

## 4. 앱에 넣기 (폰과 컴퓨터 각각)

1. 앱 → 설정 → **폰과 컴퓨터 연동**
2. 클라이언트 ID 와 시크릿을 붙여넣기
3. **구글 연결** 누르기
4. 화면에 주소(`google.com/device`)와 6~8자리 코드가 뜬다
5. 아무 브라우저에서 그 주소를 열고, **회의록을 저장할 계정으로 로그인한 뒤** 코드 입력
6. 승인하면 앱 화면이 저절로 넘어간다

폰과 컴퓨터에서 각각 한 번씩 하면 끝이다. 같은 계정으로 승인해야 서로 이어진다.

---

## 알아 둘 것

- **오디오는 올라가지 않는다.** 전사문·번역·회의록 같은 글자만 오간다.
- 켤 때, 녹음이 끝났을 때, 회의록을 만들었을 때, 그리고 3분마다 자동으로 맞춘다.
  급하면 설정의 **지금 맞추기**를 누른다.
- 양쪽에서 같은 회의록을 고쳤다면 **나중에 고친 쪽이 남는다.**
- 한쪽에서 지우면 다른 쪽에서도 지워진다. 되살아나지 않는다.
- 녹음 중인 회의는 건드리지 않는다. 끝난 뒤에 올라간다.
- 시크릿은 리포에 넣지 않는다. 기기 설정에만 저장된다.
