# 통역+회의록 설치 안내

회의를 녹음하면 글로 옮기고, 원하면 실시간으로 통역해 주고, 끝나면 회의록으로 정리해 주는 앱입니다.
안드로이드 폰에서 씁니다.

준비에 20분쯤 걸립니다. 한 번만 하면 됩니다.

---

## 미리 알아 둘 것

**이 앱은 회사 서버를 쓰지 않습니다.** 녹음과 회의록은 여러분 폰 안에만 있고,
전사와 통역을 할 때만 AI 회사로 음성이 잠깐 갔다 옵니다.

**그래서 각자 자기 열쇠(API 키)가 필요합니다.** 쓴 만큼 각자 결제됩니다.
1시간 회의에 약 300~600원 정도입니다.

---

# 1단계 · 앱 설치

## 1. APK 내려받기

폰 브라우저(크롬)로 접속합니다.

**https://github.com/Thomas-han85/MOM/releases/latest**

화면을 아래로 내려 **Assets** 를 펼치고 `meetnote-XX.apk` 를 누릅니다.
(XX 는 숫자입니다. 가장 위에 있는 것을 받으세요.)

## 2. 설치

- 다운로드가 끝나면 알림을 눌러 **열기** → **설치**
- "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 허용** 후 다시 설치
- Play 스토어에 올린 앱이 아니라서 나오는 경고입니다

## 3. 권한 허용

앱을 처음 열면 두 가지를 물어봅니다. 둘 다 **허용** 하세요.

- **마이크** — 녹음에 필요합니다
- **알림** — 화면을 꺼도 녹음이 이어지게 합니다

---

# 2단계 · OpenAI 키 만들기 (필수)

음성을 글로 옮기고, 통역하고, 회의록을 만드는 데 씁니다.

## 1. 가입

**https://platform.openai.com** 접속 → 회원가입 (구글 계정으로 가능)

주의: ChatGPT 유료 회원이어도 **별개**입니다. 여기서 따로 결제 수단을 넣어야 합니다.

## 2. 결제 수단 등록

**https://platform.openai.com/settings/organization/billing/overview**

→ **Add payment method** 로 카드 등록
→ **Add to credit balance** 로 $5~10 정도 충전

충전해 둔 금액에서 쓴 만큼 차감됩니다. 자동 결제가 걱정되면 자동 충전은 꺼 두세요.

## 3. 키 발급

**https://platform.openai.com/api-keys**

1. **Create new secret key** 클릭
2. 이름은 아무거나 (예: `daeyeok`)
3. **Create secret key**
4. `sk-` 로 시작하는 긴 글자가 나옵니다

**이 화면을 벗어나면 다시 볼 수 없습니다.** 바로 복사하세요.
복사한 값을 카카오톡 "나에게 보내기" 로 보내 두면 폰에서 붙여넣기 편합니다.

## 4. 앱에 넣기

앱 → 오른쪽 위 **톱니바퀴(설정)** → 맨 위 **OpenAI API 키** 칸에 붙여넣기
→ 맨 아래로 내려 **설정 저장**

여기까지 하면 녹음과 회의록이 됩니다.

---

# 3단계 · ElevenLabs 키 만들기 (선택)

**누가 말했는지 사람별로 갈라 주는 기능**에 씁니다.
필요 없으면 건너뛰어도 앱은 잘 돌아갑니다.

## 1. 가입

**https://elevenlabs.io** 접속 → 회원가입

## 2. 키 발급

**https://elevenlabs.io/app/developers/api-keys**

1. **키 생성** 클릭
2. 이름은 아무거나 (예: `daeyeok`)
3. 아래 **엔드포인트** 목록에서 **음성 텍스트 변환** 을 **접근** 으로 바꿉니다
   - 나머지는 접근 불가로 두어도 됩니다
4. **키 생성** → `sk_` 로 시작하는 값을 바로 복사

## 3. 앱에 넣기

설정 → **열쇠** 칸의 **ElevenLabs API 키** 에 붙여넣기 → **설정 저장**

화자 분리를 켜고 끄는 것은 녹음할 때 회의마다 고릅니다.

무료 사용량이 적어서 몇 분 쓰면 소진됩니다. 계속 쓰려면 요금제 가입이 필요합니다.

# 4단계 · 첫 녹음

1. 오른쪽 아래 **마이크 버튼**
2. 맨 위에서 모드를 고릅니다

| 모드 | 언제 쓰나 |
|---|---|
| **통역+회의록** | 대부분의 회의. 자막·통역 + 회의록까지 |
| **통역만** | 자막·통역만 보고 회의록은 나중에 |
| **회의록만** | 통역이 필요 없을 때. **값이 절반**입니다 |
| **음성파일** | 이미 녹음해 둔 파일 불러오기 |

3. **통역할 언어** — 자막을 어느 말로 볼지 고릅니다. 필요 없으면 **통역 안 함**
4. **녹음 시작**
5. 끝나면 **종료**

녹음 중에는 화면이 꺼지지 않습니다. 전사가 멈추지 않게 하기 위해서입니다.

---

# 5단계 · 회의록 만들기

노트를 열고 **문서** 탭

1. **정리 형식** 고르기

| 형식 | 쓰임 |
|---|---|
| **회의록** | 결정사항 · 미결사항 · 투두 · 요약 |
| **기타 요약** | 정해진 틀 없이 주제별 정리 (강의, 모임) |
| **참석자별** | 누가 무슨 말을 했는지 사람별로 |
| **기도회** | 공통 기도제목 + 사람별 기도제목 |

2. **분량** 고르기 — 간결 / 보통 / 상세
3. **만들기** 누르기

**+ 새 문서** 로 같은 회의에서 형식을 바꿔 여러 개 만들 수 있습니다. 앞의 것은 남습니다.

**다른 언어로** 를 누르면 회의록을 베트남어·영어로 바꿔 직원에게 공유할 수 있습니다.

# 자주 겪는 문제

**"OpenAI 키가 없다" 가 뜹니다**
→ 설정에서 키를 넣고 **설정 저장** 을 눌렀는지 확인하세요. 저장을 안 누르면 반영되지 않습니다.

**녹음은 되는데 글이 안 올라옵니다**
→ 인터넷 연결을 확인하세요. 끊겨도 녹음은 저장되고, 연결되면 밀린 것을 몰아서 처리합니다.

**"앱이 설치되지 않았습니다"**
→ 예전에 받아 둔 APK 파일이 다운로드 폴더에 남아 있으면 그것과 충돌합니다.
   다운로드 폴더에서 `meetnote` 로 시작하는 파일을 모두 지우고 다시 받으세요.

**화면을 껐더니 멈췄습니다**
→ 녹음은 이어집니다. 화면을 켜면 밀린 부분을 몰아서 처리합니다.
   회의 중 자막을 봐야 한다면 화면을 켜 두세요.

**화자 분리가 안 됩니다**
→ 녹음 시작 화면에서 **화자 분리 → 켜기** 로 두고 녹음한 회의만 됩니다.
   끄고 녹음한 회의는 소리가 이미 지워져 되돌릴 수 없습니다.

**요약이 너무 짧습니다**
→ 문서 탭에서 **분량** 을 **상세** 로 바꾸고 **다시 만들기** 를 누르세요.
