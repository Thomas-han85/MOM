# trans-mom 설치 — 요약본 (카톡 전달용)

회의 녹음 → 글로 변환 → 회의록 자동 작성. 안드로이드 폰 전용.
준비 20분, 한 번만 하면 됩니다.

---

**① 앱 설치**

폰 크롬에서 → https://github.com/Thomas-han85/MOM/releases/latest
Assets 펼쳐서 `meetnote-XX.apk` 받기 → 설치
("출처를 알 수 없는 앱" 경고 나오면 허용)
첫 실행 시 마이크·알림 권한 **허용**

**② OpenAI 키 만들기 (필수)**

1. https://platform.openai.com 가입
2. Billing 에서 카드 등록 + $5~10 충전
   (ChatGPT 유료회원이어도 여기는 별개입니다)
3. https://platform.openai.com/api-keys → Create new secret key
4. `sk-` 로 시작하는 값 **바로 복사** (다시 못 봅니다)
5. 앱 → 설정(톱니바퀴) → OpenAI API 키에 붙여넣기 → **설정 저장**

**③ 첫 녹음**

오른쪽 아래 마이크 버튼 → 모드 고르기 → 번역 대상 언어 고르기 → 녹음 시작

- **통역+회의록** : 대부분의 회의 (기본)
- **회의록만** : 통역이 필요 없을 때 (값이 절반)

**④ 회의록 만들기**

노트 열기 → 문서 탭 → 형식(회의록/기타 요약/참석자별/기도회)과 분량 고르고 **만들기**

---

**요금** — 자기 카드로 쓴 만큼 결제됩니다.
1시간 회의에 약 300~600원. 월 20시간 써도 만원 안쪽.

**주의**
- API 키는 비밀번호입니다. 남에게 보내지 마세요.
- 회의록은 폰 안에만 있습니다. 앱을 지우면 사라집니다.
- 녹음 전 참석자에게 알리세요.

**문제가 생기면**
- 키 넣고 **설정 저장**을 눌렀는지 확인
- "앱이 설치되지 않았습니다" → 다운로드 폴더의 옛 apk 파일 삭제 후 재시도
