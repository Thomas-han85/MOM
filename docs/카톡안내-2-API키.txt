[trans-mom] (2/3 · 열쇠 만들기)

앱이 도는 데 필요한 열쇠(API 키)입니다.
첫 번째는 필수, 두 번째는 선택입니다. 20분쯤 걸립니다.

━━━━━━━━━━━━━━
■ 1. OpenAI 키 (필수)

말을 글로 옮기고, 통역하고, 회의록을 만드는 데 씁니다.

① 가입
https://platform.openai.com
구글 계정으로 가입됩니다.

※ ChatGPT 유료 회원이어도 여기는 별개입니다.
   따로 결제 수단을 넣어야 합니다.

② 결제 수단 등록 + 충전
https://platform.openai.com/settings/organization/billing/overview

· Add payment method → 카드 등록
· Add to credit balance → 5~10달러 충전

충전해 둔 금액에서 쓴 만큼 빠집니다.
자동 충전은 꺼 두는 편이 마음 편합니다.

③ 키 만들기
https://platform.openai.com/api-keys

· Create new secret key 클릭
· 이름은 아무거나 (예: transmom)
· sk- 로 시작하는 긴 글자가 나옵니다

★ 이 화면을 벗어나면 다시 못 봅니다. 바로 복사하세요.
   카톡 "나에게 보내기"로 보내 두면 폰에서 붙여넣기 편합니다.

④ 앱에 넣기
앱 → 오른쪽 위 [설정] → 맨 위 "열쇠" 칸
→ OpenAI API 키에 붙여넣기
→ 맨 아래 [설정 저장]

여기까지 하면 녹음·통역·회의록이 다 됩니다.

━━━━━━━━━━━━━━
■ 2. ElevenLabs 키 (선택)

누가 말했는지 목소리로 갈라 주는 기능에 씁니다.
안 넣어도 앱은 잘 돌아갑니다. 대신 회의록에
"화자 1, 화자 2" 대신 사람 이름이 붙지 않습니다.

① 가입
https://elevenlabs.io

② 키 만들기
https://elevenlabs.io/app/developers/api-keys

· [키 생성] 클릭
· 이름은 아무거나 (예: transmom)
· 아래 "엔드포인트" 목록에서
  ★ "음성 텍스트 변환" 을 [접근] 으로 바꿉니다
  (나머지는 접근 불가로 두세요)
· [키 생성] → sk_ 로 시작하는 값 바로 복사

③ 앱에 넣기
설정 → "열쇠" 칸 → ElevenLabs API 키에 붙여넣기 → [설정 저장]

화자 분리를 켜고 끄는 것은 녹음할 때마다 고릅니다.

※ 무료 사용량이 적어서 금방 소진됩니다. 계속 쓰려면
   요금제 가입이 필요합니다. 시간당 약 0.22달러입니다.

━━━━━━━━━━━━━━
■ 첫 녹음 해 보기

① 오른쪽 아래 마이크 버튼
② 모드 고르기
   · 통역+회의록 — 대부분의 회의 (기본)
   · 통역만 — 자막만 보고 회의록은 나중에
   · 회의록만 — 통역이 필요 없을 때 (비용 절반)
   · 음성파일 — 이미 녹음해 둔 파일 불러오기
③ 통역할 언어 고르기 (필요 없으면 "통역 안 함")
④ [녹음 시작] → 끝나면 [종료]

회의록 만들기
노트 열기 → [문서] 탭 → 형식과 분량 고르고 [만들기]

━━━━━━━━━━━━━━
■ 꼭 알아 두실 것

· API 키는 비밀번호입니다. 남에게 보내지 마세요.
  새면 그 사람이 쓴 요금이 본인에게 청구됩니다.

· 회의록은 폰 안에만 있습니다. 앱을 지우면 사라집니다.
  중요한 것은 설정 → [백업 내보내기] 로 저장하거나
  노트에서 공유 버튼으로 보내 두세요.

· 녹음 전에 참석자에게 녹음 사실을 알려 주세요.

━━━━━━━━━━━━━━
■ 잘 안 될 때

"OpenAI 키가 없다" → 키 넣고 [설정 저장]을 눌렀는지 확인
녹음은 되는데 글이 안 뜸 → 인터넷 확인. 끊겨도 녹음은 남고
   연결되면 밀린 것을 몰아서 처리합니다
화면 끄면 멈춤 → 녹음은 이어집니다. 화면을 켜면 따라옵니다.
   회의 중 자막을 봐야 하면 화면을 켜 두세요
요약이 짧음 → 문서 탭에서 분량을 [상세]로 바꾸고 다시 만들기

폰과 컴퓨터에서 회의록을 같이 보고 싶으면 3/3 을 보세요.
필요 없으면 여기까지만 하셔도 됩니다.
