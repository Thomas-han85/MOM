[trans-mom] (3/3 · 폰과 컴퓨터 연결 — 원하는 분만)

폰에서 녹음한 회의록을 컴퓨터에서도 보고,
컴퓨터에서 고친 것이 폰에도 반영되게 하는 기능입니다.

필요 없으면 안 하셔도 됩니다. 앱은 그대로 잘 돌아갑니다.

━━━━━━━━━━━━━━
■ 어떻게 저장되나

본인 구글 드라이브에 "대역 회의록" 폴더가 생기고
거기에 회의록 글자만 올라갑니다.

· 녹음 파일(오디오)은 올라가지 않습니다
· 각자 자기 드라이브에 저장됩니다. 서로 섞이지 않습니다
· 다른 사람 회의록은 아무도 볼 수 없습니다

━━━━━━━━━━━━━━
■ 준비물 두 가지

아래 두 값을 관리자(한동)에게 받으세요.
모두가 같은 값을 씁니다.

· 구글 클라이언트 ID
· 구글 클라이언트 시크릿

━━━━━━━━━━━━━━
■ 연결하는 법

기기마다 한 번씩 해야 합니다. (폰 한 번, 컴퓨터 한 번)

① 앱 → [설정] → "폰과 컴퓨터 연동" 칸
② 받은 클라이언트 ID 와 시크릿을 붙여넣기
③ [설정 저장]
④ [구글 연결] 누르기
⑤ 화면에 주소와 코드가 뜹니다

   주소: https://www.google.com/device
   코드: 여덟 자리 (예: ABC-DEF-GHI)

⑥ ★ 앱 화면을 그대로 두세요. 나가거나 화면이 꺼지면
   승인해도 연결되지 않습니다

⑦ 다른 기기(컴퓨터든 폰이든)에서 위 주소를 열고
   코드를 입력 → 본인 구글 계정으로 로그인 → 허용

⑧ 앱 화면이 저절로 "연결됨" 으로 바뀝니다

폰으로 연결할 때는 컴퓨터에서 코드를 넣고,
컴퓨터로 연결할 때는 폰에서 코드를 넣는 식이면 편합니다.

━━━━━━━━━━━━━━
■ 확인

설정 → [지금 맞추기] 를 누르고
"맞췄다 · (시각)" 이 뜨면 성공입니다.

폰에서 만든 회의록이 컴퓨터 목록에 나타나는지 보세요.

━━━━━━━━━━━━━━
■ 알아 두실 것

· 한 번 연결하면 계속 유지됩니다. 매번 로그인하지 않습니다
· 켤 때, 녹음이 끝났을 때, 회의록을 만들었을 때, 그리고
  3분마다 저절로 맞춥니다
· 양쪽에서 같은 회의록을 고쳤으면 나중에 고친 쪽이 남습니다
· 한쪽에서 지우면 다른 쪽에서도 지워집니다
· 폰과 컴퓨터를 반드시 같은 구글 계정으로 승인해야 합니다.
  다르면 서로 이어지지 않습니다

━━━━━━━━━━━━━━
■ 잘 안 될 때

"the provided client secret is invalid"
→ 시크릿이 잘못 들어갔습니다. 앞뒤 공백 없이 통째로 다시 넣으세요.
   이미 넣어 둔 다른 기기가 있으면 시크릿 칸 옆 [보기] 를 눌러
   값을 확인할 수 있습니다

코드를 넣었는데 앱이 그대로
→ 기다리는 사이 앱을 나갔거나 화면이 꺼진 것입니다.
   [구글 연결] 을 다시 누르고, 이번에는 앱 화면을 켜 둔 채로
   다른 기기에서 코드를 넣으세요

"Access blocked" 또는 "확인되지 않은 앱"
→ 관리자에게 알려 주세요. 설정에서 풀어야 하는 항목입니다
