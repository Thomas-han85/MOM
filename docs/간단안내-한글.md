# 대역(trans-mom) — 간단 안내

회의를 녹음하면 **말이 멎는 대로 글이 올라오고, 통역이 귀에 들어오고, 끝나면 회의록이 나옵니다.**
한국어·베트남어·영어가 섞여도 됩니다.

---

## 1. 받기

**폰(안드로이드)** — 폰 크롬에서 열어 `transmom-###.apk` 를 받아 설치
https://github.com/Thomas-han85/MOM/releases/latest
- "출처를 알 수 없는 앱" 경고가 나오면 허용
- 처음 열 때 마이크·알림 권한을 **허용**

**노트북** — 설치 없이 그냥 열면 됩니다
https://thomas-han85.github.io/MOM/www/

---

## 2. 처음 한 번만 — OpenAI 열쇠

앱이 말을 글로 옮기고 통역하는 데 쓰는 열쇠입니다. **이것 하나면 다 됩니다.**

1. https://platform.openai.com — 가입 (구글 계정으로 됩니다)
   ※ ChatGPT 유료 회원이어도 **여기는 별개**입니다.
2. https://platform.openai.com/settings/organization/billing/overview
   → 카드 등록 → **$5~10 충전**. 자동 충전은 꺼 두는 편이 마음 편합니다.
3. https://platform.openai.com/api-keys
   → `Create new secret key` → 이름은 아무거나
   → **`sk-` 로 시작하는 값을 바로 복사** (이 화면을 벗어나면 다시 못 봅니다)
4. 앱 → 오른쪽 위 **설정** → 맨 위 「열쇠」 칸에 붙여넣기 → 맨 아래 **저장**

다른 열쇠(ElevenLabs·Anthropic)는 **안 넣어도 됩니다.**

---

## 3. 쓰기

오른쪽 아래 **마이크 단추**를 누르고 무엇을 할지 고릅니다.

### 회의
**통역+회의록** 을 고르고, 통역할 언어를 고른 뒤 녹음 시작.
- 말이 멎으면 1~2초 안에 글과 통역이 올라옵니다.
- 이어폰을 끼면 통역이 귀로 들어옵니다(아래 막대의 🎧 단추).
- 끝나고 노트를 열어 **문서 탭 → 만들기** 를 누르면 회의록이 나옵니다.

### 현장에서 직원과 (통역기처럼)
**대화** 를 고르고 내 언어·상대 언어를 고릅니다. 통역 소리를 어디로 보낼지도 고릅니다.
- **상대 말만 읽기** — 제일 간단합니다. 상대 말만 내 귀로.
- **이어폰 한 짝만 쓸 때** — 상대 말은 내 귀로, 내 말은 폰 스피커로 직원에게.
- **좌우 나눠 듣기** — 이어폰 두 짝을 나눠 끼고 각자 자기 말만 듣습니다.

녹음 중 아래 막대의 **📢** 를 켜면 내가 한 말이 베트남어가 되어 폰 스피커로 나갑니다.
한국어로 하든 영어로 하든 됩니다.

## 4. 값

내 카드로 쓴 만큼 나갑니다. **1시간 회의에 300~600원.** 말이 없는 동안은 안 나갑니다.
대화에서 「정확도 우선」을 고르면 1시간에 1,500원쯤입니다.

## 5. 알아 두실 것

- **열쇠는 비밀번호입니다.** 남에게 보내지 마세요. 새면 그 사람이 쓴 요금이 나에게 옵니다.
- **회의록은 이 기기 안에만 있습니다.** 앱을 지우면 사라집니다.
  중요한 것은 노트의 공유 단추로 내보내거나, 설정에서 구글 드라이브를 이어 두세요.
- **녹음 전에 참석자에게 알려 주세요.**
- 인터넷이 끊겨도 **녹음은 이어집니다.** 연결되면 밀린 것을 몰아서 처리합니다.

## 6. 잘 안 될 때

| 이런 때 | 이렇게 |
|---|---|
| "OpenAI 키가 없습니다" | 열쇠를 넣고 맨 아래 **저장**을 눌렀는지 |
| 글이 안 올라옴 | 인터넷 확인. 녹음은 남아 있습니다 |
| 이어폰 좌우가 안 갈림 | 폰 설정 → 소리 및 진동 → 음질 및 음향 효과 → **Dolby Atmos 끄기** |
| 이름·용어가 자꾸 틀림 | 설정 → 용어집과 그 아래 **고침 사전**(`잘못 들린 표기 → 옳은 표기`)에 적어 두기 |
| 회의록이 짧음 | 문서 탭에서 분량을 **상세**로 바꾸고 다시 만들기 |
